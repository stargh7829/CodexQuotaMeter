Windows 中文额度悬浮条 v1.1.4。

邮箱后的红色大字显示当前账号个人资料页的显示名。程序读取 Codex 客户端使用的个人资料接口中的 `profile.display_name`，显示名、额度和账号检查统一每分钟刷新。

切换账号或退出登录会清空旧昵称，旧请求晚到时丢弃。同一账号改名会在下一轮刷新同步。个人资料请求失败时额度继续更新，同一账号保留已核验的昵称，新账号暂时省略昵称。

安装包包含“一键配置.bat”和自动启动配置脚本。完整解压后双击“一键配置.bat”即可升级，随 Windows 登录启动。

验证：个人资料字段解析、登录名与显示名差异、缺失显示名、昵称更新、账号切换和异步竞态回归检查通过，并核验了当前账号的真实资料来源、浅色与深色预览。
